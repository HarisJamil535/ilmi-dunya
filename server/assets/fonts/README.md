# Paper Maker fonts

Open-licence fonts embedded in the question-paper PDFs (and EB Garamond and Poppins in Word files).
All are under the SIL Open Font License 1.1 (see OFL.txt).

- EB Garamond: https://github.com/octaviopardo/EBGaramond12
- Carlito (metric-compatible with Calibri): https://github.com/googlefonts/carlito
- Caladea (metric-compatible with Cambria): https://github.com/huertatipografica/Caladea
- Poppins: https://github.com/itfoundry/Poppins
